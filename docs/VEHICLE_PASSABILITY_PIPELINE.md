# Vehicle Passability Pipeline

The planner consumes a world-scale tractor passability product generated by the
separate `SatisfactoryMCP` repository.

Expected MCP product:

`data/local/spatial/vehicle_passability/tractor_world/tractor_passability_2m.npz`

Planner integration:

- `tools/satisfactory_route_tool/src/satisfactory_route_tool/vehicle_passability.py`
- `scripts/generate_district_surface_graph_routes.py`

The MCP-side world generator is `tools/gen_world_vehicle_passability.py` in
SatisfactoryMCP. It voxelizes raw placed geometry tile-by-tile, derives
vehicle-clear lower surfaces, and emits the canonical 2 m world passability
product. Generated MCP data is intentionally not bundled into this planner repo.
